Safety boundary

Defensive only

Synthetic
  • No RF transmission and no live EPC, HSS or network attachment.
  • No real subscriber identity, phone number or operator data.
  • Simulation state stays in the browser; only the theme preference is saved.
  • Built for training, detection validation and executive communication.

Use this workspace to practice defensive response, not to intercept or imitate a live network.

Reference

Terms you'll see

LTE shorthand
PCIPhysical Cell ID 0–503 used to distinguish LTE cells on the same frequency.
TACTracking Area Code that groups cells for paging and mobility.
RRCRadio Resource Control, the air-interface control plane.
NASNon-Access Stratum, the UE-to-core control plane.
S1-MMEThe LTE control-plane interface between eNodeB and MME.
IMSIThe subscriber identity that should only be requested after security.
EPS-AKAThe LTE authentication and key-agreement procedure.
RSRP / SINRSignal strength and signal quality measurements used in reselection.
eNBEvolved Node B — the LTE base station that owns the radio layer.
EPCEvolved Packet Core, the 4G core network behind the eNodeB.
MMEMobility Management Entity: owns attach, tracking-area and paging state.
HSSHome Subscriber Server — the subscription and authentication database.
X2The interface between eNodeBs used for handovers and ANR coordination.
ANRAutomatic Neighbor Relation: self-organizing discovery of neighbor cells.
PRBPhysical Resource Block, the scheduler's unit of radio capacity.
QCIQoS Class Identifier that labels the bearer treatment a flow receives.
TAUTracking Area Update, the idle-mode procedure that reports UE location.
PagingThe procedure that wakes idle UEs for incoming traffic, scoped by tracking area.
PLMNPublic Land Mobile Network code that identifies the operator network.
RSRQReference Signal Received Quality, the companion quality metric to RSRP.
CQIChannel Quality Indicator the UE reports to guide downlink scheduling.
IMSI catcherDefensive shorthand for a rogue cell that harvests identities pre-authentication — the scenario this lab rehearses.
